# LeetCode 热题 100 · 分板块刷题

按官方 [Top 100 Liked](https://leetcode.cn/studyplan/top-100-liked/) 的 17 个板块分目录整理，共 100 题。

每个文件都是「题目描述 + 输入输出示例 + 空 TODO 函数 + 自测 console.log」，填完函数体直接 `node xxx.js` 跑，对照注释里的期望输出验证。不看解法，先自己写。

> 说明：`✅` = 已写出实现并自测通过；`⬜` = 纯净空 TODO，待做。
> LRU 缓存属链表板块，实现已放在 [前端手写题/LRU缓存.js](../前端手写题/LRU缓存.js)，未在此重复。

## 建议刷题顺序（按面试权重）

1. **先啃高频核心空白**：哈希 → 双指针 → 滑动窗口 → 子串（这四块本地全是空的，却是面试命中率最高的）。
2. **补齐已有底子的板块**：链表还差 6 题、二叉树还差 7 题、DP 还差 2 题。
3. **次高频**：栈（全空）、二分（差 2）、回溯（差 2）。
4. **进阶拉分**：堆、图论、多维 DP、技巧。
