## 刷题顺序说明

- **P0（01-05）先啃**：链表、二叉树基本必问，哈希/双指针/滑动窗口命中率最高，先把这五块的招牌题过一遍。
- **P1（06-09）紧跟**：子串、栈、动态规划、普通数组。投全栈的话 DP 权重要往上提。
- **P2（10-17）收尾拉分**：二分、回溯、多维 DP、矩阵、堆、图论、贪心、技巧，时间够再铺开。
- 别整块清空再下一块——每个 P0 板块先做招牌题，五块招牌题过完，面试覆盖面最优。
