# 动态规划：从状态定义开始

> 这份笔记的重点不在背转移方程。**先想清楚"dp[i] 到底代表什么"**，方程会自然长出来。
> 涉及题目：[爬楼梯](../爬楼梯.js)、[打家劫舍](../打家劫舍.js)、[零钱兑换](../零钱兑换.js)、[完全平方数](../完全平方数.js)、[单词拆分](../单词拆分.js)、[分割等和子集](../分割等和子集.js)、[乘积最大子数组](../乘积最大子数组.js)、[除了自身以外数组的乘积](../除了自身以外数组的乘积.js)、[不同路径](../不同路径.js)。

---

## 一、写 DP 的固定四步

1. **定义状态**：`dp[i]` 表示什么？（这一步最重要，定错后面全错）
2. **写转移方程**：`dp[i]` 由哪些更小的 `dp[?]` 推出来？
3. **定初始值**：`dp[0]`、`dp[1]` 等边界是什么？
4. **定遍历顺序 + 返回值**：从小到大填表，最后返回哪一格。

---

## 二、线性 DP：每格由前面几格推出

### 爬楼梯 / 打家劫舍：只依赖前一两格

- 爬楼梯：`dp[i] = dp[i-1] + dp[i-2]`，`dp[i]` = 到第 i 阶的方法数。
- 打家劫舍：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`，`dp[i]` = 偷到第 i 家能拿的最大金额。选择是"偷不偷第 i 家"。
- **空间优化**：只依赖前两格时，可用两个滚动变量代替整个数组，把 O(n) 空间降到 O(1)。

### 乘积最大子数组：要同时维护最大和最小

负数会让最大变最小、最小变最大，所以要**同时维护 `maxF` 和 `minF`**：

```javascript
maxF = Math.max(x, prevMax * x, prevMin * x);
minF = Math.min(x, prevMax * x, prevMin * x);
```

遇到乘法加负数，光维护最大值不够，得把最小值也一起带上。

---

## 三、完全背包型：凑总额 / 拼凑

这一类都是"用若干个物品（可重复）凑出目标"，`dp` 下标是**金额 / 目标值**：

### 零钱兑换 `dp[i]` = 凑出金额 i 的最少硬币数

```javascript
dp[i] = Math.min(dp[i], dp[i - coins[j]] + 1);
```

- 初始 `dp[0]=0`，其余 `Infinity`（表示还凑不出）。
- 最后 `dp[amount] === Infinity ? -1 : dp[amount]`。

### 完全平方数 `dp[i]` = 凑出 i 的最少完全平方数个数

和零钱兑换同构，物品换成 `1,4,9,...`（`j*j`）。

### 单词拆分 `dp[i]` = s 前 i 个字符能否被字典拼出（布尔型）

```javascript
if (wordSet.has(s.slice(j, i)) && dp[j]) { dp[i] = true; break; }
```

- 用 `Set` 存字典，`O(1)` 查询。
- `dp[i]` 依赖"前面某个切点 `dp[j]` 为真，且 `j..i` 这段是字典词"。

---

## 四、0-1 背包型：每个数只能用一次

### 分割等和子集

判断"能否从 nums 里挑若干个数，和恰好等于 `sum/2`"。

- 先判 `sum` 是奇数直接 `false`。
- 转化为：容量为 `target = sum/2` 的背包，能否恰好装满。
- 0-1 背包（每个数用一次），一维数组时**容量要从大到小倒序遍历**，防止一个数被用多次。

---

## 五、前缀 / 后缀积：不是 DP 但同源

### 除了自身以外数组的乘积

不用除法、O(n) 时间：

- `answer[i]` = （i 左边所有数之积）×（i 右边所有数之积）。
- 先一趟从左填前缀积，再一趟从右用一个滚动变量 `r` 乘上后缀积。
- **空间优化**：把结果数组当前缀数组复用，右边用单变量滚动，O(1) 额外空间。

思想和 DP 一样：**当前答案由"已经算好的更小规模结果"拼出来**，避免重复计算。

---

## 六、网格型 / 二维 DP：dp 升成二维表

### 不同路径（LC 62）`dp[i][j]` = 从起点走到格子 (i,j) 的路径条数

机器人只能**向下**或**向右**走，反推来路：站到 (i,j) 只可能从**上面** (i-1,j) 或**左边** (i,j-1) 来，两条来路不重叠，直接相加：

```javascript
dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
```

- **地基**：第一行、第一列只有 1 条路（只能一路右 / 一路下）。技巧：建表时**全填 1**，第一行第一列自动就位，循环从 `i=1, j=1` 起步。
- **遍历顺序**：依赖上边和左边 → 从上到下、从左到右填表。
- **返回**：右下角 `dp[m-1][n-1]`。注意 `m` 是行数、`n` 是列数，别把行列搞反。

### O(n) 一维滚动数组优化

`dp[i][j]` 只依赖**正上方**和**左边**一格，所以整张表可以压成**一行 `dp[n]`**，一行一行往下滚：

```javascript
const dp = new Array(n).fill(1); // 相当于第一行
for (let i = 1; i < m; i++) {
  for (let j = 1; j < n; j++) {
    dp[j] = dp[j] + dp[j - 1]; // 右边=上边(旧dp[j]) + 左边(新dp[j-1])
  }
}
return dp[n - 1];
```

关键：`dp[j]` 更新前的**旧值 = 正上方**，`dp[j-1]` 此刻**已被本行更新 = 左边**，二者相加恰好是转移方程。空间从 O(m·n) 降到 O(n)。

## 七、建数组小抄（JS 常忘）

| 想要什么                   | 写法                                                    |
| -------------------------- | ------------------------------------------------------- |
| 长度 n，全填某值           | `new Array(n).fill(0)`                                  |
| 二维 m×n，全填某值         | `Array.from({ length: m }, () => new Array(n).fill(0))` |
| `[0,1,2,...,n-1]` 递增序列 | `Array.from({ length: n }, (_, i) => i)`                |

- `new Array(n)` 只开"空洞"，**必须跟 `.fill()`** 才能参与运算。
- 二维**千万别**用 `new Array(m).fill(new Array(n))`，所有行会共享同一个内层数组（引用共享坑，同 `res.push([...path])`）。用 `Array.from` 的工厂函数才能每行独立。
- `Array.from(参照物, 工厂函数)`：第一个参数 `{ length: m }` 只是"数量说明书"告诉它造几格；第二个工厂函数对每格执行一次，决定填什么，`(_, i)` 的 `i` 是当前下标。

## 八、怎么识别一道题是 DP / 背包？

- 问"方案数 / 最值 / 能否达成"，且**当前选择依赖之前的选择结果** → 大概率 DP。
- "从一堆物品里选若干个，凑出某个目标/容量" → 背包。
  - 每个物品**只能用一次** → 0-1 背包（分割等和子集）。
  - 每个物品**可无限次用** → 完全背包（零钱兑换、完全平方数）。
- 不一定要先认出"这是背包"才能做。**先老实定义 `dp[i]`、想转移，往往自己就走到背包的写法上了。**
