# 前端手写题 · 刷题清单

面试高频的 JS 手写题合集。这些**不是 LeetCode 算法题**，而是前端业务里"当场手写实现"的常客——考的是对语言机制（闭包、原型、this、Promise）和数据结构转换的理解。

刷法和刷 LeetCode 一样：**先自己写，写完再讲思路、讨论优化，最后沉淀笔记**。不看解法，从优先级最高的往下刷。
