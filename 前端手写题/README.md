# 前端手写题 · 刷题清单

面试高频的 JS 手写题合集。这些**不是 LeetCode 算法题**，而是前端业务里"当场手写实现"的常客——考的是对语言机制（闭包、原型、this、Promise）和数据结构转换的理解。

刷法和刷 LeetCode 一样：**先自己写，写完再讲思路、讨论优化，最后沉淀笔记**。不看解法，从优先级最高的往下刷。

## 🏷️ 优先级怎么读

每道题头部都标了两档优先级：`优先级：前端 Px · 全栈 Px`。两条线的侧重不完全一样：

- **前端线**：闭包 / this / 原型 / Promise / DOM 场景权重最高。
- **全栈线**：异步编排、并发限流、数据结构、重试/串行这类"服务端也会写"的题权重更高；纯语言 trick（instanceof、compose）稍靠后。

档位含义：**P0 必刷**（命中率最高，先啃）→ **P1 高频**（紧接着刷）→ **P2 进阶**（有余力再做，时间紧可跳过）。**两条线取高的那档来排你的顺序**：比如"并发调度器"前端全栈都是 P0，一定要会；"instanceof"前端 P1、全栈 P2，按前端 P1 对待。

> 优先级依据 2025-2026 面经帖、大厂手撕题复盘整理，反映趋势不是精确统计，投递前按目标公司再核对。

```bash
# 随便进一个分类跑就行
node 前端手写题/03-异步编程/并发控制.js
```

每个文件都是「题目描述 + 双优先级标注 + 输入输出示例 + 空函数 + 自测 console.log」。填完函数体直接跑，对照示例输出验证。
