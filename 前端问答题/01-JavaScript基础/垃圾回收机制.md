# V8 垃圾回收机制

## 核心回答（面试口述版，1 分钟能讲完）

V8 按代回收。新对象先进新生代，活得久再晋升老生代。
新生代用 Scavenge：From / To 两个半区，活着的对象复制到 To，然后互换角色。空间小、活的少，复制很快。
老生代用标记-清除，碎片多了再标记-整理。
标记时要停主线程（Stop-The-World）。V8 用增量标记、并发标记、三色标记把停顿切碎，避免一次卡几十毫秒。
泄漏常见原因：闭包抓住大对象不放、全局变量、定时器没清、DOM 删了 JS 还握着引用。
`WeakMap` / `WeakSet` 的键是弱引用，键没人用了条目会一起被收。

## 展开

1. 新生代 / 老生代的划分标准和各自的 GC 算法（Scavenge / Mark-Sweep-Compact）

新生代（Young / New Space）通常只有几 MB，再分成 From 和 To。新对象都在这。Scavenge（Cheney 算法）只扫活对象，复制到 To 区。一般活过 1～2 次 Minor GC 就晋升老生代。
老生代（Old Space）大得多。先 Mark-Sweep：从 GC Root（栈、全局、闭包上下文、DOM 引用）走一遍，没标到的清掉。洞多了走 Mark-Compact，把活对象挤到一端，更新指针。老生代还有 Large Object Space 放超大对象，不复制。

2. 什么是「全停顿」（Stop-The-World）？V8 做了什么优化？（增量标记、三色标记法）

STW 就是 GC 时 JS 停下来，不然一边标一边改堆会标错。新生代 Scavenge 本来就短；老生代全堆标记曾经能卡几十 ms。
增量标记：把标记拆成很多小片，和 JS 穿插跑。
三色：白=没访问，灰=自己标了子节点没标完，黑=子节点也标完。写屏障（write barrier）保证 JS 把黑对象指向白对象时，白的会变灰，不会漏标。
Orinoco 之后还有并发标记、并发清除、并行 Scavenge，主线程停顿压到毫秒级。

3. 常见的内存泄漏场景（闭包、全局变量、未清理定时器、DOM 引用残留）

- 闭包：外层大数组被返回的函数一直引用。函数还在，数组就卸不掉。
- 全局：`window.cache = huge`，或忘了 `var` 的赋值。
- `setInterval` / `setTimeout` 回调抓住外层对象，清定时器才能断。
- DOM：`el` 变量还在，`removeChild` 也回收不了。事件监听同样。
- Map / 对象当缓存，key 是 DOM 或大对象，没有上限也没有 WeakMap。

## 延伸

- 相关题：闭包抓住大对象、定时器没清、WeakMap 存 DOM 元数据。
- 对比题：Minor GC 很快，卡顿多半是 Major GC。有闭包不等于泄漏，看引用还在不在。
- 面试加码：Chrome Memory 堆快照找 Detached DOM；`FinalizationRegistry` 知道有这个 API 就行。

## 代码 / 例子

```js
// 1. 定时器抓住大对象
function startLeak() {
  const huge = new Array(1e6).fill('*');
  const id = setInterval(() => {
    console.log(huge.length); // huge 一直活着
  }, 1000);
  // 修：clearInterval(id)，别让回调引用 huge
  return () => clearInterval(id);
}

// 2. DOM 删了，JS 还握着
const nodes = [];
function mount() {
  const el = document.querySelector('#app');
  nodes.push(el);
  el.remove(); // 节点出树了，但 nodes 数组还引用，收不走
}
// 修：nodes.length = 0，或存 WeakRef / 不长期握 DOM
```

## 常见追问

- Q: WeakMap / WeakSet 和 Map / Set 在 GC 上的区别？
  A: Map 的 key 是强引用，key 对象即使外面没人用了，只要 Map 还在条目就在。WeakMap 的 key 必须是对象，且是弱引用：key 只被 WeakMap 握着时，GC 可以把 key 连同条目一起收掉。WeakMap 不可枚举、没有 `size`，就是为了不暴露这些随时可能消失的 key。适合 DOM 元数据、私有数据、缓存。WeakSet 同理，只有 add/has/delete。

## 自己的易错点 / 之前答崩过的地方

我以前把 Scavenge 说成「新生代也是标记清除」。新生代是复制算法，只搬活的。
闭包不等于泄漏。泄漏要看那个函数还在不在被引用。函数结束、监听卸掉，捕获的变量一样能收。
`WeakMap` 我以为 value 也是弱的。只有 key 弱，value 仍是强引用。value 想弱要用 `WeakRef`。
