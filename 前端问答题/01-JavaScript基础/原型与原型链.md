# 原型与原型链

## 核心回答（面试口述版，1 分钟能讲完）

每个对象都有 `[[Prototype]]`，浏览器里能用 `__proto__` 看到，标准方法是 `Object.getPrototypeOf`。
函数才有 `prototype` 属性，`new Fn()` 出来的对象，`[[Prototype]]` 指向 `Fn.prototype`。
`Fn.prototype.constructor` 默认指回 `Fn`。
找属性时，自己没有就沿 `[[Prototype]]` 往上走，一直到 `Object.prototype`，它的原型是 `null`，链在这里断。
`instanceof` 就是在这条链上查 `Ctor.prototype` 在不在。
`Object.create(null)` 没有原型，当字典用，不会撞上 `toString`。

## 展开

1. `__proto__`、`prototype`、`constructor` 三者的关系图

```
        constructor
   Fn ──────────────► Fn.prototype
   ▲                      │
   │ prototype.constructor│
   └──────────────────────┘

   const obj = new Fn()
   obj.__proto__ === Fn.prototype
   Fn.prototype.__proto__ === Object.prototype
```

`__proto__` 是实例身上的，指向构造函数的 `prototype`。
`prototype` 是函数身上的。
`constructor` 在 `prototype` 上，指回函数。自己改 `Fn.prototype = {}` 会把 constructor 弄丢，要补回去。

2. 原型链查找的终点是什么？`Object.prototype.__proto__` 是什么？

终点是 `null`。`Object.prototype.__proto__ === null`。
找不到属性就返回 `undefined`，不会报错。赋值默认写在对象自己身上（除非 setter 在原型上）。

3. 经典判断：`Foo.__proto__ === ?`、`Object.__proto__ === ?`

函数都是 `Function` 造出来的：
- `Foo.__proto__ === Function.prototype`
- `Object.__proto__ === Function.prototype`
- `Function.__proto__ === Function.prototype`（自己指自己这块）
- `Function.prototype.__proto__ === Object.prototype`
- `Object.prototype.__proto__ === null`

普通对象：`({}).__proto__ === Object.prototype`。

## 代码 / 例子

```js
function Foo() {}
const obj = new Foo();

// obj → Foo.prototype → Object.prototype → null
console.log(obj.__proto__ === Foo.prototype);            // true
console.log(Foo.prototype.__proto__ === Object.prototype); // true
console.log(Object.prototype.__proto__);                 // null

console.log(Foo.__proto__ === Function.prototype);       // true
console.log(Object.__proto__ === Function.prototype);    // true

function myInstanceof(obj, Ctor) {
  let proto = Object.getPrototypeOf(obj);
  while (proto) {
    if (proto === Ctor.prototype) return true;
    proto = Object.getPrototypeOf(proto);
  }
  return false;
}
```

## 常见追问

- Q: 如何判断一个属性是对象自己的还是原型链上的？
  A: `obj.hasOwnProperty('x')` 或 `Object.hasOwn(obj, 'x')`（ES2022，不怕 `hasOwnProperty` 被覆盖）。`in` 运算符会沿链找，`'toString' in {}` 是 true。`Object.keys` / `for...in` 只枚举可枚举属性，`for...in` 还会爬链，通常要配 `hasOwnProperty` 过滤。

- Q: `class` 语法和 ES5 构造函数的原型链有什么异同？
  A: 链的形状一样：实例 → `C.prototype` → `Super.prototype` → `Object.prototype`。差别在细节：class 必须 `new`，否则 TypeError；方法在 prototype 上且不可枚举；有 `super`；构造函数不提升（TDZ）；`extends` 会把子类 `__proto__` 指到父类，静态方法才能继承。ES5 手写继承还要修 `constructor` 和 `Child.__proto__`，容易漏。
