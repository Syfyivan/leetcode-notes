# 深拷贝与浅拷贝的区别

## 核心回答（面试口述版，1 分钟能讲完）

浅拷贝只复制第一层。对象里的嵌套对象、数组还是同一份引用，改拷贝会碰到原对象。
深拷贝每一层都新开，改拷贝不影响原对象。
浅拷贝常用 `Object.assign`、`{...obj}`、`arr.slice()`、`arr.concat()`、`Array.from`。
`JSON.parse(JSON.stringify(x))` 能深拷一层普通 JSON 数据，但函数、`undefined`、`Symbol`、循环引用、`Date`、`RegExp`、`Map`/`Set`、`bigint` 都会出问题。
手写深拷贝至少要处理：类型分流、循环引用（WeakMap）、`Date`/`RegExp`、数组和普通对象。
浏览器里 `structuredClone` 是标准深拷贝，循环引用、`Date`、`Map` 都能过，函数和 DOM 不行。

## 展开

1. 浅拷贝的常见手段（至少 4 种）及其各自坑

- `Object.assign({}, obj)`：只拷可枚举自有属性，不拷原型、不拷不可枚举，getter 会求值。
- `{...obj}`：和 assign 几乎一样，同是浅的。
- `arr.slice()` / `arr.concat()` / `[...arr]`：数组第一层新的，元素还是旧引用。
- `Array.from(arr)`：同样浅。
- `jQuery.extend({}, obj)`、`lodash.clone` 默认也是浅的，`cloneDeep` 才深。

2. `JSON.parse(JSON.stringify(x))` 深拷贝的局限（至少 5 类不能处理的值）

- 函数直接丢，键都没了。
- `undefined`、`Symbol` 作值会丢；作 key 的 Symbol 也丢。
- 循环引用抛 `TypeError`。
- `Date` 变成 ISO 字符串，不再是 Date。
- `RegExp`、`Map`、`Set`、`WeakMap` 变成 `{}`。
- `bigint` 直接抛错；`NaN` / `Infinity` 变成 `null`。
- 原型链丢了，拿到的是纯 `Object` / `Array`。

3. 手写深拷贝要考虑哪些点：循环引用、函数、Symbol、Date/RegExp 特殊对象

先判原始值和 null。用 `WeakMap` 记下「原对象 → 拷贝」，碰到循环直接返回已拷的那份。
`Date` / `RegExp` / `Map` / `Set` / `ArrayBuffer` 要走对应构造函数。
属性用 `Reflect.ownKeys` 才能带上 Symbol 和不可枚举。
函数一般原样返回引用（拷函数没意义），或按需求跳过。
别用 `for...in`，会抄到原型上的可枚举属性。

## 延伸

- 相关题：手写深拷贝、`isEqual`、深合并。
- 对比题：`Object.assign` / 展开运算只浅一层；JSON 方案碰到 `Date` 会变成字符串。
- 面试加码：循环引用用 WeakMap；函数、DOM 连 `structuredClone` 也过不了。MessageChannel 用的是同一套结构化克隆。

## 代码 / 例子

```js
const inner = { n: 1 };
const obj = { inner, arr: [inner] };

const a = Object.assign({}, obj);
const b = { ...obj };
const c = obj.arr.slice();
const d = JSON.parse(JSON.stringify(obj));

a.inner.n = 2;
console.log(obj.inner.n); // 2，浅拷贝共享 inner
console.log(d.inner.n);   // 1，JSON 方案当时是独立的

const cyclic = { name: 'self' };
cyclic.self = cyclic;
structuredClone(cyclic).self.name; // 'self'
JSON.stringify(cyclic);            // TypeError
```

## 常见追问

- Q: structuredClone 了解吗？相比 JSON 方案解决了哪些问题？
  A: 平台标准 API（2022 起浏览器、Node 17+）。能处理循环引用、`Date`、`RegExp`、`Map`/`Set`、`ArrayBuffer`、`Blob`，还能用 `transfer` 转移所有权。过不了：函数、DOM 节点、原型链上的方法、`Symbol` 作 key（会被丢掉）、getter/setter（只拿当前值）。错误类型是 `DataCloneError`。能用它就别用 JSON 凑。

## 自己的易错点 / 之前答崩过的地方

我以前把 `Object.assign` 说成深拷贝。嵌套对象改一下就露馅。
手写时用对象当 cache 记循环引用，key 只能是字符串，两个不同对象可能撞。必须 `WeakMap`。
`JSON` 方案拷 `Date` 我以为还是 Date，其实是字符串，`getTime` 会炸。
