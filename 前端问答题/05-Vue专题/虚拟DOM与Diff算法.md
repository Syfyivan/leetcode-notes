## 展开

1. 虚拟 DOM 的定义（JS 对象描述真实 DOM）和 3 个收益：跨平台 / Diff 后最小化操作 / 声明式编程心智负担
2. Diff 的**同层比较**原则（深度优先，不跨层）
3. **Vue2 Diff**：双端比较（4 次首尾比对）→ 找最长递增子序列确定最小移动
4. **Vue3 Diff 优化点**：
   - 静态节点提升 / 静态属性提升（PatchFlag）
   - 事件缓存
   - 动态节点用 Block Tree 收集，只比较动态部分
   - 最长递增子序列移动 + 双端指针综合
