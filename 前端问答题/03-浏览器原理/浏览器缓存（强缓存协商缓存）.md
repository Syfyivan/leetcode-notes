## 展开

1. **强缓存**：Expires / Cache-Control（HTTP/1.1）——命中时完全不发请求
   - `Cache-Control: max-age / no-cache / no-store / public / private / must-revalidate` 各值含义
2. **协商缓存**：ETag / If-None-Match（优先级高）+ Last-Modified / If-Modified-Since —— 发请求，命中返回 304
3. 完整决策流程图：先查强缓存 → 命中直用；不命中 → 走协商缓存 → 304 / 200
4. 用户行为对缓存的影响：普通刷新 / 硬刷新（Cmd+Shift+R）/ 地址栏回车
