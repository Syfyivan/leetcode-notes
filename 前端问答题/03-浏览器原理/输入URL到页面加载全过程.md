## 展开（按顺序一步步列）

1. URL 解析 & 合法性检查
2. 浏览器进程 → 网络进程发起请求
3. 强缓存 / 协商缓存判断
4. DNS 解析（含 CDN）→ 建立 TCP → HTTPS 握手
5. 服务器返回响应，网络进程接收响应体
6. 301/302 跳转处理
7. 判断响应类型（下载 / HTML / 其他）
8. 提交文档 → 浏览器进程通知**渲染进程**接手
9. 渲染进程内部：解析 HTML 生成 DOM → 解析 CSS 生成 CSSOM → 合并 Render Tree → 布局 → 绘制 → 合成 → 显示
10. Defer / async 脚本、JS 阻塞解析的细节
11. 首屏 / DOMContentLoaded / Load 三个事件什么时候触发
