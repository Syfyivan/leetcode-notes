## 展开

**语义层（RFC 规范）**：GET 是**幂等**的读操作；POST 是非幂等的写操作。这是最本质的区别。

**表现层（面试常考清单）**：

| 维度 | GET | POST |
| --- | --- | --- |
| 作用 | 读取资源（查询、列表、详情页） | 创建/修改资源（提交表单、下单、登录） |
| 幂等 | ✅ 幂等（连续发 N 次和 1 次效果一样） | ❌ 非幂等（发两次会生成两条数据） |
| 缓存 | 浏览器会主动缓存 | 默认不缓存（除非响应头显式设置） |
| 参数位置 | 放 URL query（可见、受 URL 长度限制、进历史记录） | 放 body（相对不可见、理论无大小限制、不进历史记录） |
| 安全性（传输层） | 都明文，HTTPS 下都一样安全 | 同左。别以为 POST 参数在 body 就安全，抓包都能看到 |
| 书签 / 收藏 | 可以 | 不行 |
| 浏览器刷新 / 后退 | 无害 | **浏览器会弹确认框**：数据可能被重新提交 |
| Content-Type | 不需要 | x-www-form-urlencoded / multipart/form-data / application/json |
