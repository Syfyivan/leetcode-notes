# React 合成事件（SyntheticEvent）

## 核心回答（面试口述版，1 分钟能讲完）

React 没有在每个节点上绑原生监听，而是委托到根上，再按组件树模拟捕获和冒泡。
这样做能抹平浏览器差异，方便批量更新，也能让事件带上优先级。
React 16 委托在 `document`，17 改到 root 容器，多个 React 根互不抢事件。
`e.stopPropagation()` 停的是 React 这套模拟冒泡。原生 `addEventListener` 在中间层停掉，事件到不了 root，合成事件就不会触发。
React 16 有事件池：异步里读 `e.target` 是 null，要 `e.persist()` 或先解构。17 去掉了池子。
`e.target` 是真正点到的节点，`e.currentTarget` 是你绑 `onClick` 的那个节点。

## 展开

1. 为什么要做合成事件？（浏览器兼容抹平 / 跨平台复用 / 事件委托到根节点统一管理 + 批量处理 + 优先级调度）

各浏览器事件字段不一致，React 包一层 `SyntheticEvent`。一套事件系统给 React DOM 和 React Native 共用思路。委托之后组件卸载不用挨个 remove。18 还能按 Lane 给事件更新排优先级，点击比 transition 更急。

2. 绑定顺序：原生 DOM 的捕获 / 目标 / 冒泡 **之后**，才触发 React 的合成事件冒泡；React 的捕获阶段在原生捕获阶段之前

更准确的说法：原生监听绑在你写的那个节点上，React 的监听在更上层的 root（17+）或 document（16）。
所以目标节点上的原生监听，会在事件真正落到目标时跑；React 的 `onClick` 要等事件冒泡到委托点（或捕获阶段被 root 收到）之后，再沿 Fiber 树模拟一遍。
`onClickCapture` 对应模拟的捕获。混用原生和 React 时，别靠背顺序，用 log 看，重点记住「中间 stop 会让 React 收不到」。

3. e.stopPropagation 是停的原生冒泡还是合成冒泡？（注意 React 16 和 17 的绑定位置变化：16 在 document，17 在 root 容器）

合成事件的 `stopPropagation` 停模拟冒泡，默认也会拦原生继续往上（17 的实现里会调原生 stop）。原生在子节点 `stopPropagation`：16 时 document 收不到，React 不触发；17 时 root 也收不到，同样不触发。17 改绑 root 是为了微前端：两个 React 应用互不影响 `document` 上的监听。

4. 事件对象池（Event Pooling）：React 16 会复用 e，异步访问 e 会是 null → 用 e.persist() 或提前解构；React 17 已去掉

16 为了少 GC，事件回调结束就把字段清空。`setTimeout(() => console.log(e.type))` 拿到空。`const { type } = e` 或 `e.persist()`。17 起对象不再复用，异步读是安全的。面试问池子，要补一句「17 删了」。

## 常见追问

- Q: 合成事件里 e.target 和 e.currentTarget 有什么不同？
  A: `target` 是事件起源，点按钮就是那个 button。`currentTarget` 是当前正在处理的监听节点，父 div 上的 onClick 里 currentTarget 是 div。冒泡过程中 target 不变，currentTarget 会变。委托到 root 之后，React 在模拟阶段把 currentTarget 指到你声明 onClick 的那个 Fiber 对应 DOM。

- Q: 在 React 外（原生 addEventListener 绑的）怎么阻止 React 合成事件触发？
  A: 在 React 委托点之下的节点上原生 `stopPropagation`。17 之后委托点是 root，所以 root 内部任意原生 stop 都能让这次点击的合成事件泡不到。捕获阶段在更外层拦也可以。不要依赖「先 React 后原生」这种口诀，版本一换就错。

## 自己的易错点 / 之前答崩过的地方

我在 `setTimeout` 里读 `e.target`，React 16 项目拿到 null，以为事件坏了。先解构就好。
`return false` 当原生那样当 preventDefault。React 里必须 `e.preventDefault()`。
微前端两个 React 16 应用抢 document，一个 stop 另一个没了。升 17 或把 root 分开才干净。
