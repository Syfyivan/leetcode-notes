# 垂直水平居中的几种方案

## 核心回答（面试口述版，1 分钟能讲完）

不定宽高、现在最常用：父 `display:flex; justify-content:center; align-items:center`。
Grid 一行也能做：`display:grid; place-items:center`。
absolute 三件套：`top/left: 50%` + `transform: translate(-50%, -50%)`，不要求子元素定宽高。
定宽高还可以 `inset: 0; margin: auto`。
单行文字：`text-align:center` + `line-height` 等于盒子高度。
老项目表格法：`display:table-cell; vertical-align:middle; text-align:center`。
面试至少能讲 Flex、transform、margin auto 三种，并说出各自限制。

## 展开

至少列出 **6 种**，并说明**各自的限制条件**：

1. 定宽高：负 margin（`left:50%; top:50%; margin:-w/2 0 0 -h/2`）

子元素必须知道宽高。少一半就算错。现在几乎不用。

2. 定宽高：`margin: auto` + 四方向 `0`（absolute + inset:0 + margin:auto）

```css
.box { position: relative; }
.inner {
  position: absolute;
  inset: 0;
  width: 200px;
  height: 100px;
  margin: auto;
}
```
宽高必须写死（或有固有尺寸）。不定高不行。

3. 不定宽高：`transform: translate(-50%, -50%)`

```css
.inner {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}
```
百分比 translate 相对自身。会创建层叠上下文，可能影响 fixed 子孙。亚像素模糊在某些屏上有。

4. **最常用：Flex** —— 容器 `display:flex; justify-content:center; align-items:center`

不要求子宽高。多子项也能居中。IE10 有老语法，现在校招可以当默认答案。

5. **单行内联元素**：`line-height` = 高度 + `text-align: center`

只对单行文本。多行会撑开、对不齐。替换元素（img）要再配合 `vertical-align`。

6. Grid：`display:grid; place-items:center`

`place-items` 是 `align-items` + `justify-items`。一个子元素或多个都行。兼容已经够用。

7. 表格布局（兼容老项目）：`display:table-cell; vertical-align:middle; text-align:center`

父当 table-cell。里面的块可能要改 `inline-block`。现在用得少。

## 延伸

- 相关题：Flex、position、盒模型。
- 对比题：absolute 方案父要自己撑高度；Flex 子项还在流里，副作用少。
- 面试加码：Grid 一行 `place-items:center`。单行文字才用 line-height，多行会飞出盒子。`margin:auto` 垂直居中要求有明确高度。

## 常见追问

- Q: transform 偏移方案和 Flex 方案的差别？（渲染层、性能、是否脱离文档流）
  A: transform 方案子元素是 absolute，脱离文档流，父要自己撑高度，还会提升合成层、建立层叠上下文。Flex 子项还在流里，父高度随内容，不强制图层。动画如果本来就要 transform，定位方案能顺便用合成层；静态居中用 Flex/Grid 更省事，副作用少。

## 自己的易错点 / 之前答崩过的地方

`top: 50%; transform: translateY(-50%)` 我忘了父要 `position: relative`，跑到整页中间去了。
多行文字用 `line-height` 居中，第二行直接飞出盒子。
absolute + margin auto 不定高度时我以为能居中。垂直方向没有明确 height，auto margin 算不成。
