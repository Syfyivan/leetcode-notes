# 前端问答题 · 面试八股清单

面试中「回答问题」环节的高频专题整理。每个文件一个主题，不是抄博客，而是写**你自己能顺畅讲出来的版本**——短句子、有层次、能举代码例子。

## 复习顺序建议（按面试命中率从高到低）

1. **01-JavaScript 基础**（this、原型、闭包、事件循环）—— 每一面必问
2. **02-Promise 与异步**（Promise 状态链、async/await、微宏任务顺序）
3. **03-浏览器原理**（输入 URL 全过程、缓存、跨域、安全）
4. **08-网络**（HTTP 版本、HTTPS、TCP、状态码）
5. **04-CSS 专题**（BFC、Flex、居中、盒模型）
6. **05-Vue / 06-React**（看你主栈是哪个，选一个刷深）
7. **07-工程化**（Webpack vs Vite、ESM vs CJS、Tree Shaking）

## 每个文件的写法模板

- **核心回答**：面试口述版，1 分钟能讲完
- **展开**：面试官追问时再往深说
- **代码 / 例子**：贴一段能说明问题的短代码，别贴大段源码
- **常见追问**：预判追问，先想好答案
- **自己的易错点**：之前答崩过的地方，重点记
