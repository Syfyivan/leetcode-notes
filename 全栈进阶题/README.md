# 全栈进阶题 · 后端与系统设计

投全栈岗多出来的那半场。前端半场（JS、手写、框架、网络、浏览器）在另外三个目录，这里只管**后端 + 系统设计**——它决定你能不能从"会写页面"跨到"能扛一个服务"。

写法和问答题一样：不是抄博客，是写**你自己能顺畅讲出来的版本**。每个文件五段式：核心回答、展开、代码例子、常见追问、自己的易错点。骨架里我把"展开要点"和"常见追问"当脚手架列好了，答案留空，你自己填——填的过程才是记住的过程。

## 后端语言：Go 和 NestJS 二选一主攻

两个目录都建好了，但**别两个都刷**。看你想投的方向选一门刷深，另一门了解即可：

- 走**云原生 / 基础架构 / 大厂后端**，选 **Go**。
- 已经是 **Node/TS 主栈**、想平滑扩到后端，选 **NestJS**。
